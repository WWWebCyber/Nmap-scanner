# Nmap Scanner

Небольшой скрипт на Python, который запускает Nmap, разбирает его вывод
и сохраняет найденные открытые порты в JSON-файл.

⚠️ Использовать только для сканирования своей собственной сети
или с явного разрешения владельца. Сканирование чужих систем без
разрешения незаконно и наказуемо.

## Требования
- Python 3
- Установленный Nmap

## Использование

python3 nmap_scanner.py <host> <порты>

## Пример:

python3 nmap_scanner.py 127.0.0.1 8000,8080

## Результат

Результат сохраняется в `scan.json` и выводится на экран.
